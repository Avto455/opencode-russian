# Changelog

Все значимые изменения в этом проекте документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
а проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [0.1.0] - 2026-11-13

### Добавлено
- Русский языковой пакет для OpenCode v2 (197 команд, 326 вариантов заголовков, 37 описаний, 25 групп, 52 slash-команды)
- Server-плагин с инструментом `i18n-state` для управления состоянием локализации
- TUI-плагин с shadow commands для перевода командной палитры
- Команда `/i18n` для переключения языка с сохранением выбора
- Fallback на английский при отсутствии перевода
- Инструмент `extract-commands.ts` для автоматического извлечения команд из исходников OpenCode
- Инструмент `validate-locale.ts` для проверки полноты перевода
- Инструмент `compare-locales.ts` для сравнения языковых пакетов
- Автоматические тесты (10 тестов, 1300+ проверок)
- Документация: README, INSTALL (Windows), CONTRIBUTING, TRANSLATION_GUIDE
- Шаблон для новых языков `examples/locale-template.json`
- Поддержка терминологии из ТЗ (Агент, Сессия, Контекст, Провайдер, Модель, Промпт, Инструмент, Токен, Использование, Стоимость, Разрешение, Подтверждение, Конфигурация, Рабочая директория)

### Известные ограничения
- Переводится только командная палитра (Уровень 1). Статусы, диалоги, ошибки, футеры остаются на английском (Уровень 2 требует изменений в OpenCode core).
- Плагин требует OpenCode v2.0.0+.
- Для корректного отображения кириллицы нужен современный терминал (Windows Terminal, ConEmu, VS Code Terminal).
